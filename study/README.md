# Учебный дашборд

Статический сайт (HTML/CSS/JS, без бэкенда и сборки) для навигации по курсу и
отслеживания прогресса.

## Что внутри

- Карта 18 лабораторных по фазам, с ключевыми понятиями и чек-листами задач.
- Ссылки на лекции и лабораторные (GitHub, отрендеренный Markdown).
- Копируемые команды для каждой лабы.
- Поле заметок и статус для каждой лабораторной.
- Прогресс по лабам и задачам, фильтр по фазе и поиск.
- Экспорт/импорт прогресса в JSON.

Прогресс и заметки сохраняются локально в браузере (`localStorage`), ничего не
отправляется в сеть.

## Запуск

Из корня репозитория:

```bash
python3 -m http.server 8010
```

Откройте <http://localhost:8010/study/>.

> Порт 8000 на этой машине занят, поэтому используется 8010. Можно взять любой свободный.

## Как это связано с обучением

Для написания кода используйте браузерный VS Code (code-server): <http://localhost:8011>
(пароль — в `~/.config/code-server/config.yaml`, запуск — `bash scripts/study-stand.sh`).

Дашборд — только навигация и трекер. Код пишете вы. Протокол обучения, правило
подсказок и карта чтения — в [`../LEARNING.md`](../LEARNING.md). Практика
пересборки лаб. 1 — в [`../practice/lab01/`](../practice/lab01/).

## Добавить/поправить данные

Все данные — в `data.js` (объект `COURSE`). Источник истины — `labs/*.md`; при
расхождении ориентируйтесь на файлы лабораторных.
