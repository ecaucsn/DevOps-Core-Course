# Как учиться на этом курсе

Этот файл — «штаб обучения». Здесь: протокол занятия, правило подсказок, карта чтения
по неделям и критерий «я действительно понял». Окружение описано в
[`INFRASTRUCTURE.md`](INFRASTRUCTURE.md), прогресс удобно вести в веб-дашборде
[`study/`](study/) (запуск — см. ниже).

> Главная мысль: **навык появляется, когда вы пишете код и объясняете решения сами**,
> а не когда смотрите, как его пишет кто-то другой.

---

## 1. Протокол одной лабораторной (6 шагов)

1. **Прочитать лекцию** — конкретные слайды из карты чтения ниже.
2. **Ответить на 5 вопросов** по лекции без подглядывания (устно или в конспекте).
3. **Написать самому** — по подсказкам; сначала маленький рабочий кусок, потом расширять.
4. **Объяснить** каждое нетривиальное решение своими словами в `docs/LABNN.md`.
5. **Сломать и починить** — намеренно допустить типичную ошибку и увидеть последствия.
6. **Проверить по критериям приёмки**, написать ретро и только затем коммит.

Если не можете объяснить строку — она не считается выученной, даже если «работает».

---

## 2. Правило подсказок (как помогает наставник)

Наставник (ИИ) **не пишет код за вас**, пока вы не попробовали минимум дважды. Разрешено:

- задавать наводящие вопросы;
- давать псевдокод и аналогии;
- указывать на слайд/раздел документации;
- указывать на ошибку в вашем коде и просить исправить.

Запрещено по умолчанию: вставлять готовое решение. Исключение — вы явно просите
«покажи решение», и тогда вы обязаны затем объяснить его построчно.

## 5. Критерий «понял» (Definition of Done)

- Могу объяснить каждое нетривиальное решение без подсказок.
- Могу назвать типичную ошибку и как её заметить.
- Могу воспроизвести результат с чистого листа по своим же командам.
- В `docs/LABNN.md` решения объяснены **почему**, а не пересказаны **что**.

## 7. Учебный стенд: браузерный VS Code + дашборд

Есть два веб-инструмента (оба работают локально):

**1) Стенд для кода — code-server (VS Code в браузере)**
- Адрес: <http://localhost:8011>
- Пароль: см. `~/.config/code-server/config.yaml` (поле `password`).
- Как пользоваться: войти → *Open Folder* → `/home/userdso/course/DevOps-Core-Course`
  → открыть `practice/lab01/` → терминал (`Ctrl+`` `) → писать и запускать код.
- Запуск/остановка:
  ```bash
  bash scripts/study-stand.sh        # поднять (порт 8011)
  bash scripts/study-stand-stop.sh   # остановить
  ```

**2) Трекер прогресса — статический дашборд `study/`**
- Адрес: <http://localhost:8010/> (редирект на `/study/`).
- Карта курса, чек-листы, прогресс и заметки (в браузере).
- Запуск (если не работает):
  ```bash
  python3 -m http.server 8010
  ```

> `code-server` слушает `0.0.0.0:8011` с паролем. Если машина в общей сети —
> смените пароль или привяжите к `127.0.0.1` (`BIND=127.0.0.1 bash scripts/study-stand.sh`).
