# Практика: пересборка лабораторной 1 с нуля

Цель — реально освоить то, что в `app_python/` уже есть, написав сервис **сами**.
Код из `app_python/` не копируйте, пока не пройдёте все шаги и не сравните.

Правило: наставник даёт только вопросы/подсказки. Пишете вы.

## Как работать

1. Здесь же создайте `venv` и файлы (см. шаги).
2. На каждом шаге сначала **сформулируйте план вслух**, потом пишите.
3. После шага — проверка командой и ответ на «почему».

## M0 — Теория (перед кодом)

Прочитайте `lectures/lec1.md` (слайды 1–25) и ответьте, не подглядывая:

1. Что такое «три пути» DevOps и зачем каждый?
2. Чем DevOps не является (минимум 2 пункта)?
3. Что измеряют метрики DORA (назовите 4)?
4. Почему health-эндпоинт должен быть «дешёвым»?
5. Зачем сервису конфигурация через переменные окружения, а не «хардкод»?

## M1 — Минимальный сервис

- Создайте venv и поставьте `fastapi` и `uvicorn` (закрепите версии).
- Сделайте `GET /health` → `{status, timestamp, uptime_seconds}`.
- Запустите на `0.0.0.0:5000`, проверьте `curl`.

**Проверка:** `curl -s localhost:5000/health | jq .` → 200 и 3 поля.

## M2 — `GET /`: сервис и система

- Добавьте ключи `service` (name/version/description/framework) и `system` (hostname, platform, platform_version, architecture, cpu_count, python_version).
- Uptime считайте от времени старта; используйте **timezone-aware** `datetime`.

**Вопрос:** почему `datetime.now() - START_TIME` может упасть с `TypeError`?

## M3 — `GET /`: runtime, request, endpoints

- `runtime`: `uptime_seconds`, `uptime_human`, `current_time` (ISO 8601 UTC), `timezone`.
- `request`: `client_ip`, `user_agent`, `method`, `path`.
- `endpoints`: список `{path, method, description}`.

**Проверка:** все 5 ключей верхнего уровня присутствуют.

## M4 — Конфигурация

- `HOST`, `PORT`, `DEBUG` из окружения с дефолтами `0.0.0.0`, `5000`, `False`.
- `PORT` приводите к `int`; `DEBUG` — сравнением строки в нижнем регистре.

**Вопрос:** почему `bool("False")` — плохая идея?

**Проверка:** `HOST=127.0.0.1 PORT=5050` меняет адрес/порт без правки кода.

## M5 — Ошибки и логирование

- JSON-ответы для 404 и 500.
- `logging` (уровень INFO), без `print()`.

**Проверка:** `curl -s localhost:5000/nope | jq .` → JSON, HTTP 404.
